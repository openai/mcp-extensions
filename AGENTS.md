# Building with MCP Extensions

Use this repository as a reference when building MCP apps and servers.

1. Read `docs/spec.md` for API contracts and platform support.
2. Read and apply the relevant `docs/patterns.md` guidance.
3. Follow `typescript/README.md` for TypeScript servers and apps, or `python/README.md` for Python servers. Check that the installed SDK version supports the APIs you use.
4. Use `plugins/bits-and-bolts/` for working examples.
